## 408 专项讲解

- 数据结构：明确数据规模、表示方式、下标、空结构边界，写出不变量或关键操作，再检查时间与空间复杂度；代码说明语言和伪代码约定。
- 组成原理：统一 bit/Byte、字长、地址单位、有符号数和补码约定；Cache/流水线/访存题逐项列参数，拒绝脑补硬件条件。
- 操作系统：按时序或状态表解释进程、线程、同步、调度、分页和文件系统；区分机制、策略和适用前提。
- 网络：画清层次、端到端与逐跳范围，检查单位和时延；协议细节可查 RFC，但区分教材简化模型与现行标准。
- 推荐训练采用“同一机制换参数”“边界反例”“两个相似概念辨析”；不要把知识点扩大到四门全科复习。


## 你可以直接这样问

- “我发一张题目照片，先只给一个提示。”
- “这是我的解题步骤，请指出第一个错误，给一两道变式。”
- “我还是分不清这个概念，结合资料举例说明。”
- “把这次问题整理成简短错题交接卡。”

英语仓库还支持长难句结构、语境词义、翻译与作文逐句修改。

## 能力边界

仓库提供资料与助手工作规则，回答由你正在使用的聊天模型完成。普通 ChatGPT 不会因为仓库存在而自动载入资料或保存跨聊天错题；请按手机指南连接 GitHub、读取规则并附题目。生成讲解不能冒充官方解析，机器提取不能冒充校对版。
