# 408 即时反馈示例（虚构练习，不是真实学习记录）

## 只纠正当前机制

用户：“LRU 是不是换出最先进入内存的页？”

反馈：你把“进入得最早”和“最近最久没被访问”混在一起了。前者是 FIFO 的标准，后者才是 LRU。判断 LRU 要看最后一次访问时间，而不是装入时间。

自编检验题：有两个页框，开始为空，访问顺序 A、B、A、C。读到 C 时，FIFO 与 LRU 分别换出谁？

参考推演：A、B 装入后，再次访问 A。FIFO 的装入先后仍是 A→B，故换出 A；LRU 的最近访问先后变为 B→A，故换出 B。两者此处都发生缺页，但受害页不同。不要把“给出了正确页名”当作已理解，请说明依据的是哪一个时间。
